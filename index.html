    Import Tasks from Excel

    Your Excel file must have a header row with these column names:

    Column Name Required Notes
    Task NameYesMain task title
    DescriptionNoTask details
    PriorityNoLow, Medium, or High
    StatusNoPending, In Progress, or Completed
    Assign DateNoYYYY-MM-DD format
    TagsNoComma-separated list

    Column names are case-insensitive. Extra columns are ignored. Rows without a task name are skipped.

    Daily Tasks (Sheet 2) — optional sheet named Daily Tasks:

    Column NameRequiredNotes
    Habit NameYesDaily habit title
    IconNoHabitat icon/emoji
    Date columnsNoOne per date: YYYY-MM-DD, value completed or not-completed

    Rows without a habit name are skipped. Habits whose name already exists are skipped.
